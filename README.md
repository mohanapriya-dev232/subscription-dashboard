Subscription Management Dashboard
------------------------------------
A mini SaaS Admin Dashboard that allows users to:

1. Register / Login

2. View available subscription plans

3. Subscribe to a plan

4. View active subscriptions on the user dashboard
   
Note: This project simulates backend functionality using localStorage and mock APIs inside React (src/api/fakeApi.js).
There is no external server required — all CRUD operations (auth, subscriptions, plans) work fully in-browser.
